# HyPocket Blocks

An original block game made for HyPocket: collect and build with 13 kinds of
blocks, making new ones from simple recipes (or build freely in creative
mode), in worlds that are saved on the phone, through days and nights (a day
lasts 15 minutes). The world is in ruins: creatures that came with a mist
from another dimension wrecked its villages and drag away anything alive.
By day you explore the ruins, read the notes and phone messages people left
behind and build; at night you hide in shelters (closed rooms), because the
creatures cannot be killed. The goal of each world is to light five dark
beacons: each one seals the rift the mist leaks through and keeps a lit,
mist-free sanctuary around it that the creatures never enter. Those who
are dragged away wake on the other side and must find their way back. The
story is worked out in [docs/story.md](docs/story.md). It is not related to
any other game, and all of its code, textures and sounds are made here
(textures and sounds are generated by the code).

It is also HyPocket's test bed. The game is an x86-64 Linux program using
desktop OpenGL 4.1, so it runs on Android through exactly the path a real
PC game will: Box64, Mesa's virgl driver, HyPocket's VirGL server on the
phone's GPU, and the direct display.

## Layout

| Path | What |
|---|---|
| `game/blocks.c` | The game itself (C, OpenGL 4.1, EGL). Input, statistics, audio and save formats are documented at the top and next to each structure. |
| `game/build.sh` | Builds `src/main/assets/guest-tests/blocks-x86_64` on x86-64 Linux (gcc, libegl-dev, libgl-dev). The binary is committed so others need no x86-64 toolchain. |
| `src/main/kotlin/.../BlocksSession.kt` | Runs the game through the engine and talks to it through a small shared file. |
| `src/main/kotlin/.../BlocksWorlds.kt` | The saved worlds: one `.hpw` save (written by the game) and one `.properties` file each. |
| `src/main/kotlin/.../BlocksBenchmark.kt` | The benchmark: a fixed camera path, once per set of options. |
| `src/main/kotlin/.../ui/` | The home screen (worlds), the game screen with its inventory and pause menu, touch, controller and mouse input, and the benchmark screen. |
| `src/main/kotlin/.../BlocksRecipes.kt` | The recipes, one table. |
| `src/main/kotlin/.../StoryNotes.kt` | The story's notes and phones (their words are in the string resources). |
| `docs/` | The story ([story.md](docs/story.md)), the work plan ([roadmap.md](docs/roadmap.md)), voice scripts, the player's open past and the goal ideas it grew from. |
| `src/main/kotlin/.../BlocksSettings.kt` | The settings changed in the game's own settings screen. |

## Boundaries

The module depends only on the engine's public game interface
(`io.github.hypocketapp.engine.GuestGame` and `DirectDisplay`, plus
`view.FrameSurfaceView`), and the host app hands it its settings through
`BlocksConfig`. It uses nothing from the launcher's `:app` or `:core`. That
keeps the door open to moving it to its own app and repository, with the
engine as a dependency.

## Testing on a PC

Built for x86-64 Linux, the game runs on a desktop too: with
`EGL_PLATFORM=surfaceless` and a frame count as the fourth argument it draws
that many frames on its own, and `HYPOCKET_BLOCKS_BENCH=1` makes that run a
benchmark. See the comment at the top of `game/blocks.c` for every option.
