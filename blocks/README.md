# HyPocket Blocks

An original block game made for HyPocket: collect and build with 12 kinds of
blocks (or build freely in creative mode) in worlds that are saved on the phone, through days and nights (a day lasts 15
minutes, and lamps light the dark). It is not related to any other game, and
all of its code, textures and sounds are made here (textures and sounds are
generated by the code).

It is also HyPocket's test bed. The game is an x86-64 Linux program using
desktop OpenGL 4.1, so it runs on Android through exactly the path a real
PC game will: Box64, Mesa's virgl driver, HyPocket's VirGL server on the
phone's GPU, and the direct display.

## Layout

| Path | What |
|---|---|
| `game/blocks.c` | The game itself (C, OpenGL 4.1, EGL). Input, statistics, audio and save formats are documented at the top and next to each structure. |
| `game/build.sh` | Builds `src/main/assets/guest-tests/blocks-x86_64` on x86-64 Linux (gcc, libegl-dev, libgl-dev). The binary is committed so others need no x86-64 toolchain. |
| `src/main/kotlin/.../BlocksSession.kt` | Runs the game through the engine and talks to it through a small shared file. |
| `src/main/kotlin/.../BlocksWorlds.kt` | The saved worlds: one `.hpw` save (written by the game) and one `.properties` file each. |
| `src/main/kotlin/.../BlocksBenchmark.kt` | The benchmark: a fixed camera path, once per set of options. |
| `src/main/kotlin/.../ui/` | The home screen (worlds), the game screen, touch, controller and mouse input, and the benchmark screen. |

## Boundaries

The module depends only on the engine's public game interface
(`io.github.hypocketapp.engine.GuestGame` and `DirectDisplay`, plus
`view.FrameSurfaceView`), and the host app hands it its settings through
`BlocksConfig`. It uses nothing from the launcher's `:app` or `:core`. That
keeps the door open to moving it to its own app and repository, with the
engine as a dependency.

## Testing on a PC

Built for x86-64 Linux, the game runs on a desktop too: with
`EGL_PLATFORM=surfaceless` and a frame count as the fourth argument it draws
that many frames on its own, and `HYPOCKET_BLOCKS_BENCH=1` makes that run a
benchmark. See the comment at the top of `game/blocks.c` for every option.
