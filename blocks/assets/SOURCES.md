# Origem dos arquivos

Uma linha por arquivo (ou por grupo do mesmo jeito, como `player_struggle_1..4`),
no mesmo commit que o arquivo. Regras em [README.md](README.md).

- **Ferramenta:** o que fez o arquivo. Para IA, o produto e o modelo como
  aparecem na tela (por exemplo "Adobe Firefly, Firefly Sound Effects").
  Para gravação, o aparelho ou app.
- **Como:** "gravado", "desenhado", "gerado" ou "gerado e editado".
- **Pedido:** para IA, o texto pedido, resumido. Ajuda a refazer e mostra
  que nada imita obra de outro.
